# Can We Detect LLM-Generated Text?

**A Linguistic and Stylometric Study of Human and Synthetic Movie Reviews**

This repository contains the code, data-processing workflow, and result files for an NLP research poster project at Universität Trier.

## Research Questions

1. How do human-written and LLM-generated movie reviews differ in linguistic and stylometric features?
2. How accurately can simple linguistic features distinguish human-written from LLM-generated reviews?
3. Do these features generalize across different LLMs?

## Study Design

The study uses a paired design with **400 texts**:

- 200 human IMDb movie reviews
- 100 reviews generated by **GPT-4o-mini** (LLM A)
- 100 reviews generated by **Claude Haiku 4.5** (LLM B)

Human and generated reviews are matched by film, sentiment direction, and approximate length range (100–150 words). Both LLMs use the same prompt template and temperature (0.7).

## Features

Eleven interpretable linguistic and stylometric features are extracted across five groups:

- **Lexical:** type-token ratio (TTR; first 100 tokens)
- **Sentence:** average sentence length
- **POS:** noun, verb, adjective, adverb, and pronoun ratios
- **Sentiment:** absolute VADER compound score
- **Punctuation:** comma, exclamation-mark, and question-mark rates

## Classification

The classifier is a standardized logistic regression model.

Evaluation uses 5-fold `StratifiedGroupKFold`, grouped by film ID (`tconst`), so that a human review and its generated counterpart never appear in different folds.

## Main Results

- Human vs. synthetic classification: **94.2% mean accuracy**
  - SD = **2.4 percentage points**
  - F1 = **0.943**
- POS-only ablation: **94.8% accuracy**
- Cross-model transfer:
  - LLM A → LLM B: **95.5%**
  - LLM B → LLM A: **80.5%**
- **25 of 33** pairwise feature comparisons remained significant after Bonferroni correction (`α ≈ 0.0015`)

Cross-model transfer was asymmetric, indicating that strong in-domain detection performance does not necessarily imply equally strong performance on an unseen generator.
